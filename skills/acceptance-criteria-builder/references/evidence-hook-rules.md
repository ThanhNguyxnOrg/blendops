# Evidence hook rules

Each **P0** criterion should state:

1. **Artifact type** — PNG, GLB, log excerpt, preview report section.
2. **Truth label target** — Usually `Produced` minimum before stakeholder demo; `Verified` only with recorded checks.
3. **Validator** — Which skill or human review proves it.

Forbidden hooks:

- "Engineer says it's fine" without observable signal.
- Automatic `Verified` for subjective mood without signed stakeholder note.

Align wording with `render-export-evidence` ledger fields.
