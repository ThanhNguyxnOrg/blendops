# Brief → criteria mapper

| Brief slot | Example acceptance themes |
|---|---|
| Subject | silhouette, scale cues, focal hierarchy |
| Mood | lighting contrast, palette bounds, fog/volume limits |
| Camera | framing rules from composition checker |
| Materials | PBR plausibility, texture resolution caps |
| Outputs | format, resolution, animation, real-time budget |
| Constraints | time stops, scope bans |

Procedure:

1. List slots present in brief.
2. For each, emit 1–3 criteria max at first pass (avoid checklist explosion).
3. Tag priority P0/P1/P2.
4. Attach hook lines.

Emit final table sorted by P0 first.
