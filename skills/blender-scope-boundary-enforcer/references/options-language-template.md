# Options-language template

## The 3 options (always offer all three)

### 1. Decline

"Proceed with original scope."

When to recommend:
- Addition contradicts the brief.
- Time / budget exhausted.
- The user is in evaluation mode, not commitment mode.

### 2. Add now (with agreement)

"Agree to new scope: <updated stop condition>. Cost: <time / gate / budget>."

When to recommend:
- Addition is small or medium AND fits the same recipe semantically.
- Time budget allows.
- The addition strengthens the original deliverable rather than diluting it.

### 3. Defer

"Track as follow-up recipe (no current scope change)."

When to recommend:
- Addition is large or new modality.
- Brief already locked.
- Adding now would multiply gates beyond manageability.
- Deferral is almost always safer than absorption.

## Phrasing tips

- Always show all three options, even if recommending one.
- State the **cost** of "add now" explicitly (time, gates, budget).
- State the **followup-recipe-name** for "defer" (helps the user track it).
- Use neutral language; do not push the user toward your preference.

## Decision evidence

When the user picks an option, record it:
- Picked option (1 / 2 / 3)
- Time of agreement
- Updated stop condition (if option 2)
- Follow-up recipe name (if option 3)

This serves as evidence per `evidence-before-done.md` for the scope state.
