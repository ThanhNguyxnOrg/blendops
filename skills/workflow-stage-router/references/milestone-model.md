# Milestone model (conceptual)

Stages are logical — not Git branches.

1. **Intent** — brainstorming / help / brief
2. **Fit & prerequisites** — recipe fit, pack prerequisites, runtime path intent
3. **Planning** — scene / camera / lighting / assets
4. **Quality planning** — budgets, validators to run
5. **Execution** — upstream Blender work (out of skill scope except guidance)
6. **Evidence** — render-export-evidence, preview reports
7. **Handoff** — GLB web, plain-language response, pre-handoff verification

Inventory hints:

- Brief only → Intent / Fit
- Plans without artifacts → Planning complete → Execution prep or evidence skills if doing dry validation of plans only (text mode)

Always pair execution talk with runtime truth labels.
