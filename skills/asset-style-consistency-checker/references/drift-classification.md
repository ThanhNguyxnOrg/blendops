# Drift classification

## When drift is OK

- Brief explicitly calls for mixed style.
- Subject vs background intentional contrast (focus play).
- Editorial / collage aesthetic.

## When drift is NOT OK

- Default product hero / portrait / arch viz: drift breaks visual hierarchy.
- Multi-product grid: drift breaks catalog uniformity.
- Branded marketing: drift dilutes brand consistency.

## Severity scale

| Severity | What it looks like | Action |
|---|---|---|
| None | Assets share all 4 axes | Continue |
| Minor | One axis slightly off | Note; usually accept |
| Major | Two axes off | Replace or restyle |
| Severe | 3+ axes off | Block; cannot mix |

## Top-line aggregation

- All assets None → Pass.
- One Minor → Warn.
- Any Major or Severe → Fail.

## Remediation options

1. **Replace**: find a different asset that fits.
2. **Restyle**: reauthor the asset to match (modeling work).
3. **Drop**: remove the asset from the scene.
4. **Reframe brief**: explicit decision to accept mixed style.

Most often: replace is best (cheapest, cleanest).
