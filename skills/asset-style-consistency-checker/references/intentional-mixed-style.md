# Intentional mixed-style

When the brief explicitly calls for mixed style, the consistency check inverts: drift becomes feature, uniformity becomes risk.

## Common intentional-mixed cases

### Editorial collage
Subject realistic, background flat 2D, props cartoon. Each chosen for narrative contrast.

### Hybrid 2D + 3D
3D subject composited over 2D illustrated background. Style boundary is the design.

### Style frame transitions
Multiple panels / shots showing the same character in different styles.

### Mood-driven contrast
Subject high-detail to draw eye, surroundings deliberately simplified.

## What to verify when mixed-style is intentional

- The brief explicitly states the mixed-style intent.
- Each "style island" is internally consistent (e.g., the stylized props all match each other even if they don't match the subject).
- Visual hierarchy still works (subject reads first).
- The mix is repeatable across the deliverable (not random).

## Common mistakes in "intentional mixed-style"

- "It's intentional" used as escape hatch for actually-broken assets.
- No internal consistency within style islands.
- Visual hierarchy lost (eye does not know where to land).
- Mix changes mid-deliverable (frame 1 has different mix than frame 2).

## Verdict in mixed-style case

- If brief is explicit + style islands consistent + hierarchy works → Pass even with axis-level drift.
- If brief is vague + drift is just there → Fail; not actually intentional.
