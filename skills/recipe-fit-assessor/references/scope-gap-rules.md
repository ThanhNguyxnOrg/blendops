# Scope gap rules

## Upgrade to Strong fit when

- Deliverable type matches pack outputs (still / turntable / GLB / anim).
- Complexity fits stated time budget.
- Reference style aligns with pack assumptions (studio vs environmental).

## Downgrade to Partial fit when

- Multiple incompatible outputs requested simultaneously without prioritization.
- Asset sourcing strategy unknown while pack assumes licensed libraries.
- Interactive real-time app constraints conflict with offline render plan.

## Poor fit triggers

- Pack assumes product silhouette clarity but user needs macro material study only.
- Legal distribution requires asset types the pack does not cover.
- User requires concurrent multi-user editing (out of scope for Draft v0 skills).

Document each gap as a user-visible bullet with a mitigation (narrow scope, pick different planner, split projects).
