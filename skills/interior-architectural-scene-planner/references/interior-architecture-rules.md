# Interior architecture rules

## Standard room dimensions

| Room type | Typical area (m²) | Typical ceiling (m) |
|---|---|---|
| Bedroom (single) | 9–14 | 2.4–2.7 |
| Bedroom (master) | 14–25 | 2.4–2.7 |
| Living room | 16–35 | 2.4–3.0 |
| Kitchen | 8–18 | 2.4–2.7 |
| Bathroom | 4–10 | 2.3–2.6 |
| Open-plan living/dining | 30–60 | 2.7–3.5 |
| Hotel lobby | 50–200 | 3.5–6.0 |
| Office (small) | 10–30 | 2.7–3.0 |
| Office (open-plan) | 50–500+ | 2.7–3.5 |

## Floor / wall / ceiling

| Style | Floor | Walls | Ceiling |
|---|---|---|---|
| Modern minimalist | Light wood / polished concrete | White / light gray | Flat white |
| Mid-century modern | Wood (medium tone) | Cream / olive / accent walls | White |
| Industrial | Concrete | Exposed brick / dark gray | Exposed beams / ducts |
| Scandinavian | White-washed wood | White | White |
| Traditional | Hardwood | Cream / muted | Coffered |
| Hotel hospitality | Marble / travertine | Wood paneling / fabric | Coffered / dropped |

## Windows

- Natural light driver — plan window placement before furniture.
- Window-to-floor ratio: 10–25% for daylit spaces.
- Orientation matters: south-facing (NH) gets sun all day; east = morning; west = afternoon; north = soft diffuse.
- Single window vs floor-to-ceiling vs corner glazing → very different look.

## Doors

- Position relative to camera: avoid placing prominent door behind subject.
- Standard door: 0.9m × 2.1m.

## Common consistency failures

- Modern minimalist style + ornate Victorian moldings → Fail.
- Floor-to-ceiling window + heavy curtains in modern brief → Warn.
- Mixed era furniture without intent → Fail.
