# Anti-patterns

- **Standalone Connector myth** — Anthropic tutorial requires Blender Lab MCP add-on inside Blender.
- **Path 1 version creep** — Do not imply Path 2 needs Blender 5.1+; the Lab manifest floor applies to Path 1 only.
- **Dual bridges** — Never advise running Path 1 + Path 2 attach simultaneously on one Blender instance.
- **CLI dismissal** — CLI fallback appendix is documented upstream as a **first-class** Blender CLI surface; BlendOps has **no in-repo evidence file yet**, not "unsupported Blender feature".
- **Vendor guarantee** — Picking a path is not a promise the user's IT environment permits it.
