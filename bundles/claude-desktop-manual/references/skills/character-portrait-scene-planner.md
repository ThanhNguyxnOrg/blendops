# character-portrait-scene-planner

Purpose: plan a single-character portrait scene (subject, pose, expression, wardrobe, framing, lighting, background) before any modeling or render.

Use when intent is a character / person / creature portrait. Distinct from product-hero-scene-planner (products), environment-establishing-shot-planner (wide outdoor), interior-architectural-scene-planner (rooms).

Return structured plan with Subject / Pose / Wardrobe / Camera / Lighting / Background / Mood + Style sections, asset list flagged for blender-asset-discovery-planner, evidence label.

Hand off to blender-asset-discovery-planner / composition-quality-checker / lighting-quality-checker.
