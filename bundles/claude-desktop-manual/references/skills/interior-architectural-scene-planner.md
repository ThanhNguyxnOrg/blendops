# interior-architectural-scene-planner

Purpose: plan an interior architectural visualization scene (room dims, style, furniture, materials, natural + artificial lighting, camera) before any modeling or render.

Use when intent is interior room / venue / showroom / hospitality / residential / office.

Do not use for outdoor / establishing shots, single product hero, or character portraits.

Return structured plan with Room / Architecture / Furniture / Material palette / Lighting (natural + artificial) / Camera / Mood + time-of-day sections, asset list flagged, evidence label.

Hand off to blender-asset-discovery-planner / composition-quality-checker / lighting-quality-checker / material-quality-checker.
