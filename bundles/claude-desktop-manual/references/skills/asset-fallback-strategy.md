# asset-fallback-strategy

Purpose: provide a fallback strategy when an asset is unavailable / over-budget / license-blocked / style-incompatible — without halting the recipe.

Use after a checker fails an asset.

Do not silently substitute without user agreement.

Return 2-3 fallback options (Replace from open / Replace from paid / Procedural / Generative / Drop with caveat) scored on time / brief match / license, recommendation, required user agreement, updated asset list.

Hand off to discovery for selected fallback or scope reduction if all blocked.
