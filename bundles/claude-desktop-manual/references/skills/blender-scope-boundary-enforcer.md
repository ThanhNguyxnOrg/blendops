# blender-scope-boundary-enforcer

Purpose: detect mid-recipe scope creep and force user to decline / agree-to-new-scope / defer; prevents silent absorption.

Use mid-recipe when scope drift is detected.

Do not use during early planning or brainstorming.

Return scope decision record (addition / 3 options / recommendation / required agreement), updated stop condition if added, recipe-split note if deferred.

Hand off to blender-recipe-decomposer for "defer" path.
