# blender-stop-condition-decider

Purpose: define one explicit "done" condition for a Blender recipe before starting work, plus an out-of-scope list. Inspired by Anthropic Superpowers `/just-say-when-it's-done` analog.

Use before any non-trivial Blender recipe.

Do not use for pure brainstorming or after work has already started without scope.

Return one concrete stop condition, 3-5 out-of-scope items, handoff trigger, mode label, evidence label.

Hand off to blender-checklist-driven-workflow (gates) or pre-handoff-verification (final gate).
