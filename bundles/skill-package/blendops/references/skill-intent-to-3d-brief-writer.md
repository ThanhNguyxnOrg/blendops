# intent-to-3d-brief-writer

Purpose: convert confirmed intent into an 8-slot structured 3D brief. BMad analysis-phase analog adapted for 3D and non-Blender users.

Use right after `blender-brainstorming` confirms intent, OR when the user provides a structured request. Skip if intent is still ambiguous (route to brainstorming).

Output contract: brief with 8 slots (Subject, Mood/style, Deliverables, Constraints, Evidence expectations, Acceptance criteria, Audience, Owner). Decisions deferred to planners listed explicitly. User echoes and confirms before handoff. Runtime status `Not Run`. Hand off to relevant planner.
