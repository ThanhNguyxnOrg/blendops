# asset-library-organization-planner

Purpose: plan an internal asset library structure (folders, naming, metadata, license tracking, version control) so future recipes find and reuse assets reliably.

Use when starting a new repo with multiple recipes, when existing library is disorganized, or before scaling to 50+ assets.

Do not use for single-recipe repos with < 5 assets; do not use as a substitute for license check.

Output contract: folder tree, naming convention, metadata schema, version control rules, license tracking strategy, review process, migration steps if existing library.
