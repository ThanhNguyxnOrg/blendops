# asset-fallback-strategy

Purpose: provide a fallback strategy when an asset is unavailable / over-budget / license-blocked / style-incompatible — without halting the recipe.

Use after a checker fails an asset, or when an asset cannot be acquired in time.

Do not use when no asset has failed; do not silently substitute without user agreement.

Output contract: 2-3 fallback options scored on time / brief match / license, recommendation, required user agreement, updated asset list, caveat lines if "drop" chosen.
