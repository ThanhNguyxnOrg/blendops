# environment-establishing-shot-planner

Purpose: plan a wide environment / establishing-shot scene (locale, time of day, weather, atmosphere, camera, depth layers, focal subject) before any modeling or render.

Use when intent is establishing a place (wide / outdoor / landscape / cityscape).

Do not use for character portraits, product hero, or interior arch viz.

Output contract: structured plan with Locale / Time / Weather / Atmosphere / Sky / Camera / FG-MG-BG / Focal subject / Mood sections, asset list flagged for discovery, evidence label.
