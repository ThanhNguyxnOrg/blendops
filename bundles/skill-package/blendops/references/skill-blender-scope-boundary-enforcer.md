# blender-scope-boundary-enforcer

Purpose: detect mid-recipe scope creep ("can you also...") and force user to either decline / agree-to-new-scope / defer to follow-up recipe; prevents silent absorption.

Use mid-recipe when scope drift is detected ("while you're at it", "actually let's also", "one more thing").

Do not use during early planning (scope is naturally fluid) or during brainstorming.

Output contract: scope decision record (addition / 3 options / recommendation / required user agreement), updated stop condition if added, recipe-split note if deferred.
