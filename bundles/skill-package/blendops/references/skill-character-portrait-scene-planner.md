# character-portrait-scene-planner

Purpose: plan a single-character portrait scene (subject, pose, expression, wardrobe, framing, lighting, background) before any modeling or render.

Use when intent is a character / person / creature portrait. Distinct from product-hero-scene-planner (manufactured products), environment-establishing-shot-planner (wide outdoor), interior-architectural-scene-planner (rooms).

Do not use for multi-character ensembles, product hero, or environment scope.

Output contract: structured plan with Subject / Pose / Wardrobe / Camera / Lighting / Background / Mood + Style sections, asset list flagged for discovery, evidence label.
